# POLLNEX
PollNex Insights (par Pollnex) dynamise le commerce haïtien avec des données : analyses de marché, conception d’enquêtes en Haïti, échantillonnage, modélisation statistique et tableaux de bord décisionnels pour exécutifs et partenaires. At POLLNEX, we combine proprietary and public data to cut through noise and deliver one thing only: verified facts. https://pollnex.com
